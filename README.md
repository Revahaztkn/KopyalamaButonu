# KopyalamaButonu

KopyalamaButonu, sık kullandığın metinleri renkli noktalara kaydedip tek tıkla Windows panosuna kopyalamanı sağlar. E-posta adreslerini, bağlantıları veya hazır mesajları ekranın kenarında elinin altında tutabilirsin.

**[Windows x64 için indir (ZIP)](https://github.com/Revahaztkn/KopyalamaButonu/releases/download/versiyon/Serial-Copy-Button-Windows-x64.zip)** · [Sürüm notları](https://github.com/Revahaztkn/KopyalamaButonu/releases/tag/versiyon)

## Başlarken

1. Windows x64 ZIP dosyasını indir ve bir klasöre çıkar.
2. Çıkardığın klasördeki `Serial-Copy-Button.exe` dosyasını aç.
3. Ekranın kenarındaki renkli noktalardan birine sol tıkla. Metni istediğin yerde **Ctrl + V** ile yapıştır.

## Noktaları kullanma

| İşlem | Nasıl yapılır? |
| --- | --- |
| Metin kopyala | Renkli noktaya sol tıkla. |
| Metni gör veya düzenle | Fareyi noktanın üzerinde beklet. Açılan karttan **Düzenle** seçeneğini kullan. |
| Yeni nokta ekle | Şeritteki **+** düğmesini kullan. |
| Noktaları grupla | Nokta eklerken veya düzenlerken **Grup** alanına örneğin `İş` ya da `Kişisel` yaz. |
| Nokta ara | Şeritteki **⌕** düğmesiyle başlık, metin veya grup adına göre ara. **Şeride uygula** yalnızca eşleşen noktaları gösterir. |

## Yedekleme ve taşıma

- **Noktaları dışa aktar** seçeneğiyle kayıtlarını bir JSON dosyasına yedekle.
- Başka bir bilgisayarda **Noktaları içe aktar** seçeneğiyle yedeğini yükle. Var olan kayıtlar korunur ve birebir aynı kayıtlar yeniden eklenmez.
